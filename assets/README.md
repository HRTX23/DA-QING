# DA QING art

Created with the built-in imagegen tool for this project. Original assets, inspired by the user's references for a warm illustrated narrative interface.

- `east-palace.png`: Wide hand-drawn storybook Qing private nursery, morning sunlight, cream plaster, red lattice windows, jade curtains, peach daybed, wooden toys, orchid and courtyard greenery. No people, text or UI.
- `yue-lan.png`: Original 2D court lady Yue Lan in a full-length peach robe with jade trim, black hair bun and flower hairpin, gentle smile, folded hands. Warm brown outlines, pastel colors, paper texture; transparent background.

The first visual release uses this nursery illustration across the story view. Additional location art, character expressions and sequential comic scenes remain future work.
