# DA QING — Prototype 0.1

เกมสวมบทบาทจักรพรรดิชิงในประวัติศาสตร์ทางเลือก เริ่มวันที่ 21 ตุลาคม 1948 เวลา 06:25 น. เล่นเป็นหงจิ้น อายุ 18 เดือน

## เล่นเกมผ่านเว็บ

ลิงก์สำหรับเปิดเล่นเมื่อ GitHub Pages เผยแพร่สำเร็จ: https://hrtx23.github.io/DA-QING/

ใช้ได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์ผ่านเบราว์เซอร์สมัยใหม่ ไม่ต้องดาวน์โหลด ZIP เล่นเกมโดยกดตัวเลือก หรือพิมพ์การกระทำพื้นฐาน เช่น มอง แม่ พ่อ เล่น พักผ่อน เปลี่ยนเมนูเพื่อดูราชวงศ์ แผนผังพระราชวัง พงศาวดาร และจัดการเซฟ

เซฟอยู่ในเบราว์เซอร์ของแต่ละเครื่อง หากต้องการย้ายเครื่อง ให้ส่งออก JSON จากเมนูบันทึกเกม แล้วนำเข้าไฟล์ที่เครื่องใหม่ การล้างข้อมูลเว็บไซต์อาจลบเซฟได้

## รันในเครื่องสำหรับพัฒนา

เปิด `index.html` ด้วยเบราว์เซอร์สมัยใหม่ผ่านเว็บเซิร์ฟเวอร์ภายในเครื่อง เช่น

```bash
python3 -m http.server 8000
```

แล้วเปิด http://localhost:8000/ บนคอมพิวเตอร์ เครื่องอื่นในเครือข่ายเดียวกันต้องใช้ IP ของเครื่องที่รันเซิร์ฟเวอร์และตั้งค่าการเข้าถึงให้เหมาะสม

> การเผยแพร่เว็บใช้ GitHub Pages จากสาขา `main` โฟลเดอร์ `/ (root)`; ไฟล์เกมหลักคือ `index.html`, `src/main.js` และ `src/world.js`

## ระบบที่เล่นได้
- ฉากเนื้อเรื่องและบทสนทนา
- เวลาและกิจกรรมที่ส่งผลต่อพงศาวดาร
- ทะเบียนตัวละครราชวงศ์ตาม Canon
- แผนผังตำหนักต้นแบบ 2D (ไม่ใช่ผังสถาปัตยกรรมตามมาตราส่วน)
- คำสั่งภาษาไทยพื้นฐานที่ตรวจสอบตามวัย
- บันทึก/โหลดด้วย localStorage และส่งออก/นำเข้า JSON
- เหตุการณ์สำคัญตามกำหนดเวลา
- Responsive สำหรับมือถือและเดสก์ท็อป

## ข้อจำกัดที่ตั้งใจไว้
- Prototype เป็นเว็บแบบ client-side ยังไม่ใช่ backend PostgreSQL / AI API
- บทสนทนาเป็นชุดเหตุการณ์ที่กำหนดไว้ ไม่ใช่ AI แบบอิสระเต็มรูปแบบ
- วันเริ่มต้นเป็น Canon; หลังข้ามวันยังไม่มีกิจกรรมเฉพาะรายวันครบทุกวัน
- แผนที่ยังเป็นการจัดตำแหน่ง UI ไม่ใช่แผนที่พระราชวังที่สำรวจและตรวจสอบเชิงภูมิศาสตร์แล้ว
- ยังไม่รองรับการซิงก์เซฟข้ามอุปกรณ์โดยอัตโนมัติ

## แนวทางรุ่นถัดไป
แยก simulation engine ออกจาก frontend, เพิ่ม Fastify API, PostgreSQL/Prisma, event scheduler หลายวัน, NPC autonomy, การตรวจสอบ Canon อัตโนมัติ และ AI narrative แบบมี guardrails
